# 要件定義書フォルダ

研修スライドで紹介する各システムの要件定義書（Markdown）を置くフォルダです。
スライドの内容は、ここにある定義書に書かれた事実だけをもとに作成します。

## ファイルの置き方

- 1システム1ファイル（例：`shokuinroku.md`、`tsunagari-meibo.md`）
- ファイル名は半角英数字とハイフンを推奨

## 記載してほしい項目（わかる範囲で）

- システム名と目的
- 利用者と利用場面
- 使用技術（Excel VBA、PowerShell、HTML/JavaScript など）
- データの保存場所
- 動き方（何をきっかけに、何を処理し、何を出力するか）
- 画面例（スクリーンショットを使う場合はダミーデータで）

## 入れてはいけないもの

- 個人情報（実在の職員名・連絡先など）
- APIキー、パスワード、認証情報
- 公開できない庁内情報

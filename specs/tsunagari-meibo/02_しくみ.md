# しくみ

## 全体像

CSVを読んで人物マスターを組み立て、**単一のHTML（つながり名簿.html）を出す。**
中間ファイルは作らない。HTMLはデータを自分の中に持っていて、`file://` で開いて完結する。

```
01_CSVを入れる ──┐
                 ├→ build-master.ps1 →  02_できたものを見る
03_判断を書き込む ┘                        つながり名簿.html
       ↑                                    取扱説明書.html
       └──────── 画面から直接書く ──────────┘
                （File System Access）
```

**人が書いたものは 03 に置き、機械が読む。画面はその 03 に直接書く。**
書いたものは次の取り込みで名簿に入る。取り込みは1日1回、自動で回る。

| 使えるもの | 何でも | Windows PowerShell 5.1、Excel、Edge |

**受け渡しに無害化ゲートウェイがある。**HTMLの `<script>` は消され、`.ps1` と `.bat` は
そのままでは通らない。だから**HTMLはテンプレートをBase64で `.ps1` に埋め込んで運び、
庁内で初めて生成する。**スクリプトは末尾に `.txt` を付けて運び、庁内で外す。

詳しいきまりは `.claude/rules/庁内の環境.md`（いいねぇ隊フォルダ共通）。

## 処理の流れ（build-master.ps1）

1. **実行前の確認** … 置き場、CSVの有無、**書き出すファイルが開かれていないか**
2. **台帳を読む** … 採番台帳、統合判断、手で入れたこと、データソース一覧
3. **下見** … 採番と名寄せの準備。同じCSVを2回読むのでキャッシュする
4. **読み込みと照合** … ソースを日付順に読み、人物にまとめる
5. **手で入れたことを当てる** … いちばん最後。人が書いたものが機械より強い
6. **組み立て** … 集計、統合候補、要確認、変更履歴の差分
7. **HTML出力** … viewer.html にデータを埋めて `つながり名簿.html` を書く
8. **控え** … `02_できたものを見る\控え\yymmdd\HHmm\` にCSV一式

所要時間は私用PCの実データ2,169人で **40〜87秒。ばらつきが大きい**（読み込みと照合が
22〜51秒で振れる）。業務端末では測っていない。

## 実行のしかた

**庁内**は `実行する.bat` をダブルクリック。ふだんは自動実行に任せる。
**名簿は `画面を開く.bat` から開く**（2026-09-25）。課共有フォルダの html をダブルクリックするとアドレスにサーバー名が入り（`file://（サーバー名）/...`）、Edge が保存先フォルダを選ばせない（AbortError）。bat は `pushd` でドライブ文字を付けて開き、8秒待ってから外す。窓で `\\（サーバー名）` をたどって選んだフォルダは、ドライブが外れたあとも書ける（庁内で確認）。

**開発側**は次のとおり。

```powershell
powershell -ExecutionPolicy Bypass -NoProfile -File "tools\build-master.ps1"
```

引数は `-Root`（課フォルダの作り）、`-InDir`、`-OutDir`、`-NoBackup`、`-Open`。

## 試すとき

私用PCで確かめられることは私用PCで確かめる。ダミーデータには正解表があり、名寄せの
正解率が測れる。

**氏名や住所が入っていないと確かめられないものだけ**を庁内に残す。
`実データ（個人情報抜き）` は氏名・住所・備考・部局・課・役職などが**全件空**なので、
そこを通る処理は**手元で通っても何も証明していない**。

画面のJSは、headless DOM（jsdom）で読み込みまで動かせる。**構文が通ったことは
動くことではない。**過去に、JS文字列に生の改行が入って画面が真っ白になったことがある。

## 開発の地雷

`~/.claude/開発メモ_Windows環境.md` と `.claude/rules/PowerShellとファイル.md` が正。
この案件でとくに踏んだもの。

- **日本語を含む `.ps1` は UTF-8 BOM付きで保存する。**BOMが落ちると cp932 として読まれ、
  日本語が全部化けて構文エラーになる。**エラーの文面まで化けるので原因が読めない**
- `$pid` は PowerShell の予約変数。**書き込めない。**人物IDには使わない
- `Join-Path` に `'取込済\日付'` と1回で渡すと区切りが消える。2回に分ける
- `-replace` の置換側の `$_` は入力全体に展開される。`.Replace()` を使う
- PowerShell の変数名は大文字小文字を区別しない（`$L` と `$l` は同じ）
- 旧々logoフォームは**データ行の先頭に余分な列が1つ入っていて全体が右へずれている。**
  読むときに直している

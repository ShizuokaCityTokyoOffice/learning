# 画面

**元は `tools\viewer.html`。**build がBase64で埋め込み、庁内で `つながり名簿.html` になる。
`file://` で開いて完結する。外部のCDN、Webフォント、外部画像、fetch は使えない。

## 構え

上に見出し帯。**タブは2つだけ。**

| タブ | 何を出すか |
|---|---|
| **名簿**（既定） | 人を探し、絞り、カルテで1人ぶんを見る。書き出しもここから |
| **答える数字** | 会員数、累計、関係者数、年度別の推移、この数字の出どころ |

見出し帯の右に2つのボタン。

- **手を入れるもの**（未処理の件数つき） … 統合候補、要確認、まだ取り込まれていない入力
- **設定** … 職員番号と、保存先フォルダ
- **職員番号が未設定**（入っていないときだけ出る） … 押すと設定が開く。保存するものは全部これで止まるので、
  押す前に知らせる（2026-09-11）

**タブに出さない画面**は、各画面の中のボタン（`data-go`）から開く。
統合候補 `cand`、要確認 `rev`、前回からの変化 `henka`、取り込んだファイル `torikomi`、
この数字の出どころ `konkyo`。

## 配色

**色は2つだけ。**

- **紺** … 確定した数字と、その根拠。**動かないもの**
- **橙** … 人の判断が要るもの、まだ確定していないもの、公表値と合わないもの

トークンは `viewer.html` の `:root`（`--accent` `--warn` ほか）。取扱説明書も同じ配色。

## 名簿（一覧）

- **出す列は画面で選ぶ。**開いた直後は8列。幅は選ばれた列の重みで100%に配り直すので、
  何本選んでも横スクロールは出ない
- 検索は氏名、カナ、S番号、所属、都道府県、住所、メール、電話に効く。スペース区切りのAND
- 入口のチップは帯ごとに見出しを付ける。**同じ帯の中は「どれか」、帯どうしは「どちらも」**
- **見出しを押すと1つのメニューが開く。**上が並べ替え、下がその列の値の一覧
- **いま効いている条件は表のすぐ上に1行で並び、1つずつ × で外せる**
- 行は折り返さず、高さをそろえる

## カルテ（1人ぶん。右からスライドイン）

**毎回見るのは基本情報だけ。**残りは畳む。**中身が無い節は見出しごと出さない。**

1. **この人のこと** … 人物マスターの主な項目
2. **備考（関係者システム）** … 除隊や経緯が書かれているので畳まない
3. 畳む節 … `所属の移り変わり` / `手で直した記録` / `静岡市交流会` / `関わりの記録` / `変わったこと` / `この番号の出どころ`

**所属の移り変わり**（2026-09-24）は「前はどの部署だったか」に答える節。元の行（名寄せ前の値）の
法人名・部局・課・役職と、手で直した所属の行を新しい順に並べる。元の行の同じ組は1つにまとめ、
いちばん新しい日付を出す。手で直した行は直した欄だけを出し、ほかは「—」。1通りしか無い人には出さない。
**手で直した記録**（2026-09-24）は `手で入れたこと.csv` のその人の行（日時・入力者・種類・項目・値・理由）。
元のデータのほうが新しくて使われなかった行には、その旨を添える。どちらも消去済の人には出さない。

**静岡市交流会は、ほかの行事と別枠**で出す。

## 手を入れるもの

**統合候補**
- 1行ごとに「同一人物／別人／保留」を押す
- 保存すると `統合判断_追加_日時_職員番号.csv` を書く
- 別人と判断した組は「候補に戻す」で戻せる

**要確認**
- **左の列が「この行をどうしますか」。理由の列をその次に置く**（2026-09-11。右端だと横に送らないと読めなかった）
- チェックを付けられるのは、理由に「人物マスターに一致しない」を含み、かつ
  電話番号・メールアドレス・LINEユーザーIDのどれかを持つ行だけ
- **氏名だけの行は名簿に載せず、要確認に残す**
- まとめて登録すると、関係者区分＝イベントのみ、会員状態＝非会員で入る
- **備考と便りの届け方の食い違い**の行は「発送不要にする」「郵送のままでよい」を押す。**押すとその場で保存。**
  どちらも `便りの届け方` の行を1つ書き、取り込みは便りの届け方を人が入れた人を二度と出さない
- 名簿にいる人の行には「この人を開く」（カルテが開く）。以前は行を押しても何も開かなかった

**まだ取り込まれていない入力**
- `03_判断を書き込む` のフォルダを読んで数える。**ほかの人が入れたぶんも数に入る**

## 新しい人を足す、この人を直す

入口は2つ。一覧の上の「新しい人を足す」と、カルテの「この人を直す」。**書く先は同じ形。**

| | 新しい人を足す | この人を直す |
|---|---|---|
| 見出し | 新しい人を足す（1 まず探す → 2 中身を入れて保存する） | この人の登録を直す（S番号と氏名） |
| 最初の1行 | 分かる欄を入れて保存する。（必須）は必ず入れる | 直したい欄だけ書き換えて保存する。変えていない欄はそのまま |
| 必須の印 | 姓・名・関係者区分・便りの届け方 | 出さない |
| 決めるボタン | 下の帯に「保存する」「やめる」 | 同じ。「保存する（2 項目）」のように変えた数が出る |
| やめる | 探す画面へ戻る | カルテへ戻る |
| 保存した後 | 探す画面へ戻り「保存しました」 | カルテへ戻り、上に「保存しました」と直した項目 |

- **保存は1回押すだけ**（2026-09-11）。以前は「台帳に加える」で画面に溜め、3段目の「CSVで保存」で初めて書いていた
- **探すところから始まる。候補を見ないまま新規登録に進む道は作らない**
- 書き換えた欄は橙になる。空にした欄は書かない（そう画面に出す）
- 入力者は設定の職員番号で埋める。**職員番号が無いと保存させない**（受付番号とファイル名が 0000 になるため）
- 日時は秒まで入れる。同じ日に同じ欄を2回直しても、取り込みが2回目を「同じ行」として捨てないように
- 入れかけで閉じる・Esc・外側を押したときは、捨ててよいかを聞く
- 受付番号は画面が発行する（`関係者-20260908-481637-01`）。取り込み済みの最大（`meta.teNo`）と、
  フォルダの追加ファイル・本体を読んで続きから振る（`03_データ.md` の受付番号）
- この画面で足した人は、探したときに候補に出る（「この画面で足した」。選べない）。同じ人を二度足さないため
- **保存後の施錠はやめた**（2026-09-08）
- **会員は作れない**（`04_ルール.md`）

## 取り込みが済んだことの知らせ（2026-09-16）

見出し帯のすぐ下に出る帯。**保存したものが取り込まれたら、その場で言う。**

- 見分け方は「この画面が保存先フォルダへ書いたファイルが、そこから消えたこと」。取り込みは `取込済` へ移す
- 60秒ごとに見る。保存先フォルダを選んでいないときは何もしない
- **消えた（NotFound）ときだけ数える。**許可が外れただけのときに「取り込まれました」と言わない
- 「名簿を読み直す」で読み直す。**画面は自分では入れ替わらない**（file:// なので外から更新できない）

## 出席の記録

「出席を記録」で専用の画面を開く（2026-09-24 作り直し）。**イベントを選ぶと、そのイベントの申込者だけが並ぶ。**
来た人に印を付けて保存すると `出席_日時_職員番号.csv` を書く。行のどこを押しても印が切り替わる。
申込をせずに来た人は、同じ画面の「申込をせずに来た人を足す」で名簿から探して足す（足した人は一覧の上にまとめる）。
出席を記録済みの人は「記録済み」と出て、印を付けられない（二重に数えない）。

- 並ぶイベントは、関わりの記録のうち結果が「参加」（申込）の行を名称ごとにまとめたもの。新しい順。
  関係者システムの交流会の出欠（案内状への返事）は入れない
- 一覧は、申込者と、申込なしで出席を記録済みの人と、この画面で足した人
- 取り込みは `出席の記録.csv` に積み上げてから数える（`03_データ.md`）。接点履歴に入り、出席回数が増える
- **申込と出席は別物。**

2026-09-08 版は、一覧（2,000人）にチェック欄を出して来た人を探す形だった。受付で手元にあるのは
申込者の名簿なので順番が逆で、しかも申込者の6割が名簿に結び付いておらず一覧に出てこなかった。

## 書き出し（この○人を書き出す）

いま絞り込んでいる人だけを出す。コピー欄とCSV保存、宛名ラベルの印刷。

**開いた直後は何も選ばない。**「何に使いますか」と、使い道で3つに分けた札を出す（2026-09-24 作り直し。
それまでは11個のボタンを同じ重みで横に並べていて、何ができるか読み取れず、宛名ラベルが埋もれていた）。
札の下の行に、押す前に何件出るかを出す。札を押すと、その下に中身・除いた内訳・次のボタンが出る。

| 群 | 札 | 中身 |
|---|---|---|
| 送る | 宛名ラベルを刷る | 郵送する相手だけ。A4に21面。枠を太くして目立たせる。台紙は刷る画面で選ぶ（下の節） |
| 送る | メールで送る / LINEでタグを付ける | 1列。見出しを付けない（貼り先が壊れるため） |
| Excelで使う | 名簿の一覧 | 列を選ぶ |
| Excelで使う | 宛名の表 | 郵送する相手だけ。差し込み印刷用の10列 |
| Excelで使う | 関わりの記録 / アンケート回答 / 行事の参加 | 人にぶら下がる表 |
| くわしい記録（畳む） | 外部ID / 名寄せ前の値 / 統合の記録 | 人にぶら下がる表 |

「メールで送る」は、絞り込んだ人のメールアドレスを便りの届け方に関係なく全部出す。
イベントにだけ来た人（関係者区分「イベントのみ」）も入るので、送る前に絞り込みで対象を決める。

### 宛名ラベルの刷る画面（2026-10-13 作り直し）

交流会の照合用ブックの宛名ラベル（同日に作り、庁内の紙で確かめた版）でやっていることを移した。
刷る相手の決まり（便りを郵送する人だけ、住所か郵便番号がある、消去済は除く。`labelTargets`）は変えていない。

上に細い帯が1本（いま何名を並べているか、台紙の名前、印刷のボタン、タブ）、その下にやる順の段が4つ、その下に台紙。
画面に貼り付くのは帯だけ。

- **段1 だれの分を刷りますか。**「全員」か「一部の方だけ」。一部は氏名を入れる欄が1つ（氏名かフリガナの一部、人物IDでも読む。読点か改行で区切る）。
  入れたそばから並び、確定のボタンは無い。1名に決まれば並べ、何名も当たれば候補を出して押した方だけ足す。同じ氏名の方が2名いれば2名とも並べて知らせる。
  並んだ方は札で出て × で外せる。一部だけ並べている間は帯の色を変え「全員ではなく ○ 名だけ」と出す。何も入れていなければ誰も並べず、印刷のボタンは押せない。
  **集まり（会員だけ、ある課の分だけ）を決めるのは名簿の一覧の絞り込みで、この欄は、その中のばらばらの数人を刷り直すためだけのもの**
- **段2 どの台紙の、どこから刷りますか。**台紙は A-One 28924（70×42.3mm、紙の上の余白0.45mm）と 28931（70×38.1mm、同14.8mm）。
  **`画面を開く.bat` から開いたときは 28924**（2026-10-13 ユーザー。選び直した台紙は、読み込み直しても、刷る画面を閉じて開き直しても、その画面を開いている間は残る）。選ぶとその場で割り付けが切り替わり、収まるかも調べ直す。
  使いかけの台紙は、台紙の絵で「もう使った面」を押すか、なぞって選ぶ（飛び飛びでもよい。2026-10-13 ユーザー）。1枚目の白い面にだけ順に置く。21面すべては選べない
- **段3 収まらない方がいないか。**人数と「一覧を開く」
- **段4 印刷する。**ボタンの字が何名を刷るかを言う。収まらない方が残っていても止めず、横に赤い字で知らせる。枠線、Wordで開く、PDF で記録を残す案内もここ

決めたことと、その理由。

- **台紙ごとに違う数字（高さと紙の上の余白）は `viewer.html` の `LABEL_STOCKS` の1か所だけ。**縁の7mm、内側の余白、字の大きさは `LABEL_BOX`・`LABEL_PT` と CSS の `.lbl` の両方にあり、変えるときは両方を直す。台紙ごとに違うのは高さと紙の上の余白だけで、CSS の変数（`--top`、`--h`、`--pt1`、`--pbL`）にして
  `#labelSheets` に付ける。「Wordで開く」も同じ表から計算する
- **紙の縁から7mmは字を置かない。**左右の端の列に加えて、上下に余白の無い 28924 では1段目の上と7段目の下も（内側が 6.55mm になる）。
  28931 ではこの手当ては効かず、割り付けは 2026-08-26 からの版と同じ（285面で位置と字の差0を確かめた）
- **機械が黙って字を小さくしない。小さくするのは人が押したときだけ。**面を押すと出る調整の窓で、行（郵便番号、住所、方書、所属、氏名）ごとに 70〜100% を5%ずつ。
  「おまかせ」は氏名以外を85%まで、足りなければ全部の行を70%まで下げ、収まらなければ100%に戻す。すでに収まっている方には何もしない。
  その方のその行にだけ `--k1`〜`--k5` を付ける。**画面だけのもので、どこにも残さない**
- **タブ「収まらない方」**に、誰が、どの行のせいで、何mm収まらないかを1人1行で出す。一度でも収まらなかった方は、収まった後も緑の行で残す。
  名簿そのものを直す道は、いまある「この人を直す」（新しい仕組みは作らない）
- **「収まりません」の赤い字は紙にも出す**（2026-10-13 ユーザー。それまでは刷るときに消していた）。面を囲む枠は紙に出さない
- **選んだ台紙だけは読み込み直しても残す**（アドレスの末尾の `#d2`）。**台紙のほかは、刷る画面を開くたびに初めの状態へ戻す。**
  欄と実際の割り付けが食い違うと、違う台紙の寸法で刷る、絞り込んだつもりで全員を刷る、が起きる。帯、段4、印刷のときの題に、いまの台紙の名前を必ず出す
- **紙詰まりで途中の枚から刷り直すのは、印刷の画面のページ指定に任せる**（2026-10-13 ユーザー。「○人目から」の欄は作らない）。
  台紙1枚が印刷の1ページで、何枚目かを台紙の左上に画面だけ出す
- **「Wordで開く」は、いま並べているとおりに出す**（台紙、並べている方、空けた面、小さくした字）。28924 は用紙の余白0、行42.3mm固定で、
  1段目の上を7mm、7段目の下を6.1mm空ける。Word は折り返す位置が画面と違うので、画面で収まっていても Word で収まるとは限らない
- 空白の無い長い英数字は折り返す。前は右で切れ、収まらない方として出なかった
- 2026-10-13 reviewer の指摘で直したこと。刷るときの決まり（名簿の画面を消して台紙だけ出す）は、刷る画面を開いている間だけ効かせる（前は「根拠の1枚」を刷ると白紙になり、残っていた宛名ラベルが刷られた）。一部の方だけの間に一覧の「ラベルで調整」を押しても全員には戻さず、その方を足す。× で外した方は、欄の言葉がその方に当たっている間は外したまま（別の方を足しても戻らない）。候補から押した方の覚えは、言葉を消したら捨てる。Edge の「最小フォント サイズ」で字が縮まない端末では、収まったことにしない。刷る画面を開いている間は「/」で検索欄へ飛ばさない。直しは再レビューしていない
- 分かっていないこと。収まるかは画面の組みで調べている。紙では折り返す位置が変わり、画面で収まった方が紙で欠けることが無いかは、紙でしか分からない
- 試験は `tools\_試験用\label_test.py`（私用PC。Edge を playwright で動かす）

元データの調べ（住所や連絡先の食い違い、列の中身、備考の書き方）は画面では出さない。
`情報の新しさを調べる.bat` が庁外へ出せる .txt を1本出す（2026-09-11）。

## 設定（最初の1回だけ）

- **職員番号** … 受付番号に入る。番号が衝突して片方が消えるのを防ぐ
- **保存先フォルダ** … `03_判断を書き込む` を1回選ぶ。File System Access で直接書く。
  **画面が `\\サーバー\...` から開かれていたら（`location.host` が空でない）、選べないことを先に出す**（2026-09-25。庁内で AbortError になった）。
  開くのは `画面を開く.bat` から（`pushd` のドライブ文字の側で開く）。
  フォルダはIndexedDBに覚える。許可が残っていればそのまま使う。ブラウザは画面を開き直すと許可を
  「未確認」に戻すので、そのときは見出し帯に「前の保存先を使う」を出し、**人が押したときにだけ**
  `requestPermission` で確かめる（設定の「このフォルダを使う」も同じ。2026-09-25、v102）。
  **保存を押したときに黙って確かめる作り（v94〜v98）は採らない。**当時、庁内の Edge で「フォルダを選んでも反応しない」
  になった。v101 で分かったのは、選ぶ窓は閉じるのに AbortError が返り、それを取り消しとして黙って捨てていたこと。
  確かめる窓を何度も出すと Edge が自動で断るようになったとみている（未確認）。
  選ぶ窓に目印（`id`）は付けない。v99 で付けたところ、開き直したあとの2回目に選べなくなった。
  選べなかったとき・確かめて断られたときは、**取り消し（AbortError）も含めて**理由を設定の中に出す

**File System Access が `file://` で効くことは業務端末で確認済み**（2026-09-08。
`isSecureContext: true`、ドライブをまたいだ書き込みも通った）。
選んでいないときはダウンロードに落ちるので、`03` へ人が移す。

## 壊してはいけないもの

- **画面に出る数字は、取り込んだ時点の確定値。**その場の入力で動かさない
- **まだ確定していない入力が何件あるかを、開いた人に必ず伝える**
- **数字のとなりに、その数字の根拠への入口を置く**
- **列を1本足すときは `$liteP` にも足す**（`03_データ.md`）

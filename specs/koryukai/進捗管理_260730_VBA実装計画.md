# 交流会進捗管理システム VBA実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** UX設計書（`2026-07-30_交流会進捗管理システムUX設計書.md`）に基づき、東京事務所職員が説明書なしで30秒以内に進捗更新できるマクロ付きExcelブック（.xlsm）を1本納品する。

**Architecture:** PowerShellからExcel COMオートメーションでワークブックを構築し、`Application.VBE`経由でVBA標準モジュール・UserFormのコードをテキストとして注入する（AccessVBOM=1で許可確認済み）。シートはワークシート直接編集方式（UserFormはタスク編集の1つのみ）。データはExcel名前付き範囲・ListObjectテーブルのみで保持し、外部DBやJSONファイルは使わない。

**Tech Stack:** Excel 2016以降（Version 16.0で確認済み）、VBA、PowerShell 5.1（ビルドスクリプト、Excel COM自動化専用。納品物には含めない）。

## Global Constraints

- シートは「進捗入力」「使い方」「設定」の3枚のみ。追加禁止。
- UserFormは「タスク編集」用の1つのみ。
- ボタンは「進捗を保存」「タスク編集」（メイン画面）、「新規追加」「選択を編集」「保存」「削除」「キャンセル」（タスク編集画面）のみ。
- ラベルは動詞＋目的語で明確に（例：「進捗を保存」であって「更新」ではない）。
- フォントは游ゴシック11pt。保存ボタンは青、削除は赤、完了は緑、期限切れは赤。背景は薄いグレー、入力欄は白。
- 進捗更新の操作は「分野選択→タスク選択→保存」の3クリック以内で完結させる。
- 検索は入力の都度即時絞り込み（Googleライク、検索ボタンなし）。この要件を満たすため検索ボックスのみActiveX TextBoxを使用する（タスク一覧本体はユーザー承認済みの通り素のセル＋条件付き書式）。
- 初期データ移行元：`250715_所内打合せ\R8やることスケジュール(係打合せ用)_250715決定反映.xlsx`。開催当日タスクの期限は令和9年1月13日（2027-01-13）に補正する。

- Modify: `交流会進捗管理.xlsm`（設定シート）

**Interfaces:**
- Consumes: Task1で作成した`交流会進捗管理.xlsm`（シート「設定」）
- Produces:
  - 設定シート セル配置：`A1:A11`=分野一覧（A1見出し＋10分野）、`B1:B7`=担当一覧（B1見出し＋6担当）、`C1:C2`=イベント一覧（C1見出し＋1件）

  - タスクマスタテーブル：`E1:O1`が見出し（ID, 分野, タスク名, 担当, 期限, 完了, 進捗, 現状, 課題, 今後, 更新日時）、ListObject名`T_タスク`
  - 名前付き範囲：`rngCategoryList`=`設定!$A$2:$A$11`、`rngPersonList`=`設定!$B$2:$B$7`、`rngEventList`=`設定!$C$2:$C$2`、`rngCategoryFilter`=`設定!$Q$1:$Q$12`、`rngPersonFilter`=`設定!$R$1:$R$8`
  - 後続タスクはこのテーブル`T_タスク`の列順（ID=1列目からO=11列目まで）に依存する。

- [ ] **Step 1: 移行元データの解析関数を含むビルドスクリプトを作成する**

```powershell
# 進捗管理システム\build\02_setup_settings.ps1
$ErrorActionPreference = "Stop"
$outPath = "C:\Users\（ユーザー名）\Documents\静岡市交流会\交流会進捗管理システム\交流会進捗管理.xlsm"
$srcPath = "C:\Users\（ユーザー名）\Documents\静岡市交流会\R8静岡市交流会\00_input\250715_所内打合せ\R8やることスケジュール(係打合せ用)_250715決定反映.xlsx"

$categories = @("全体管理","各所への報告","シナリオ","PRブース・ホワイエ","パンフレット","案内状・招待者・受付","料理","スタッフ関係","お土産","つり銭・調定・支払関係")
$persons    = @("担当A","担当B","担当C","担当D","担当E","担当F")

function Convert-JunToDate {
    param([int]$month, [string]$jun)
    # 7月～12月は2026年、1月は2027年（令和8年度=2026年4月～2027年3月）
    $year = if ($month -eq 1) { 2027 } else { 2026 }
    $day = switch ($jun) {
        "上旬" { 5 }
        "中旬" { 15 }
        "下旬" { 25 }
        default { 15 }
    }
    return (Get-Date -Year $year -Month $month -Day $day)
}

# ソースを読み、分野列(3..12)×行(3..23)からタスクを抽出する
$excel = New-Object -ComObject Excel.Application
$excel.Visible = $false
$excel.DisplayAlerts = $false
$srcWb = $excel.Workbooks.Open($srcPath)
$srcSheet = $srcWb.Sheets.Item(1)
$range = $srcSheet.Range("A1:P23")
$values = $range.Value2

$tasks = @()   # 各要素: @{分野=..; タスク名=..; 期限=[datetime]}
$curMonth = $null
$curJun = $null
for ($i = 1; $i -le $values.GetLength(0); $i++) {
    $monthCell = $values[$i, 1]
    $junCell   = $values[$i, 2]
    if ($monthCell) { $curMonth = [int]([string]$monthCell -replace '月','') }
    if ($junCell) { $curJun = [string]$junCell }

    # 「21日」のような日付直書き行（開催当日）は上旬/中旬/下旬ではないため個別処理
    $isEventDayRow = ($curJun -match '日$')

    for ($col = 3; $col -le 12; $col++) {
        $cell = $values[$i, $col]
        if (-not $cell) { continue }
        $cat = $categories[$col - 3]
        $lines = ([string]$cell) -split "`n"
        foreach ($line in $lines) {
            $t = $line.Trim()
            if ($t -notlike "□*") { continue }
            $title = ($t -replace '^□', '').Trim()
            if ($isEventDayRow) {
                $due = Get-Date -Year 2027 -Month 1 -Day 13   # 案件.md確定日に補正
                if ($title -eq "開催当日") { continue }        # 「開催当日」自体はタスクではない見出しなので除外
            } else {
                $due = Convert-JunToDate -month $curMonth -jun $curJun
            }
            $tasks += [PSCustomObject]@{ 分野 = $cat; タスク名 = $title; 期限 = $due }
        }
    }
}
$srcWb.Close($false)
Write-Output ("抽出タスク数: " + $tasks.Count)

# ここから交流会進捗管理.xlsm に書き込む
$wb = $excel.Workbooks.Open($outPath)
$ws = $wb.Sheets.Item("設定")

$ws.Cells.Item(1,1) = "分野"
for ($k=0; $k -lt $categories.Count; $k++) { $ws.Cells.Item($k+2,1) = $categories[$k] }

$ws.Cells.Item(1,2) = "担当"
for ($k=0; $k -lt $persons.Count; $k++) { $ws.Cells.Item($k+2,2) = $persons[$k] }

$ws.Cells.Item(1,3) = "イベント"
$ws.Cells.Item(2,3) = "令和8年度交流会"

# フィルタ用（すべて + 一覧）Q列・R列
$ws.Cells.Item(1,17) = "すべて"
for ($k=0; $k -lt $categories.Count; $k++) { $ws.Cells.Item($k+2,17) = $categories[$k] }
$ws.Cells.Item(1,18) = "すべて"
for ($k=0; $k -lt $persons.Count; $k++) { $ws.Cells.Item($k+2,18) = $persons[$k] }

# タスクマスタ見出し E1:O1
$headers = @("ID","分野","タスク名","担当","期限","完了","進捗","現状","課題","今後","更新日時")
for ($k=0; $k -lt $headers.Count; $k++) { $ws.Cells.Item(1, 5+$k) = $headers[$k] }

$rowIdx = 2
$id = 1
foreach ($t in $tasks) {
    $ws.Cells.Item($rowIdx, 5)  = $id
    $ws.Cells.Item($rowIdx, 6)  = $t.分野
    $ws.Cells.Item($rowIdx, 7)  = $t.タスク名
    $ws.Cells.Item($rowIdx, 8)  = ""
    $ws.Cells.Item($rowIdx, 9)  = $t.期限
    $ws.Cells.Item($rowIdx, 9).NumberFormat = "yyyy/mm/dd"
    $ws.Cells.Item($rowIdx, 10) = $false
    $ws.Cells.Item($rowIdx, 11) = ""
    $ws.Cells.Item($rowIdx, 12) = ""
    $ws.Cells.Item($rowIdx, 13) = ""
    $ws.Cells.Item($rowIdx, 14) = ""
    $ws.Cells.Item($rowIdx, 15) = ""
    $rowIdx++
    $id++
}
$lastRow = $rowIdx - 1

# ListObjectとして登録
$tblRange = $ws.Range($ws.Cells.Item(1,5), $ws.Cells.Item($lastRow,15))
$lo = $ws.ListObjects.Add(1, $tblRange, [System.Reflection.Missing]::Value, 1)  # xlSrcRange=1, xlYes=1
$lo.Name = "T_タスク"

# 名前付き範囲
$wb.Names.Add("rngCategoryList", $ws.Range("A2:A11")) | Out-Null
$wb.Names.Add("rngPersonList",   $ws.Range("B2:B7"))  | Out-Null
$wb.Names.Add("rngEventList",    $ws.Range("C2:C2"))  | Out-Null
$wb.Names.Add("rngCategoryFilter", $ws.Range("Q1:Q12")) | Out-Null
$wb.Names.Add("rngPersonFilter",   $ws.Range("R1:R8"))  | Out-Null

$wb.Save()
$wb.Close($false)
$excel.Quit()
[System.Runtime.Interopservices.Marshal]::ReleaseComObject($excel) | Out-Null
Write-Output ("設定シート構築完了。タスク件数: " + ($lastRow - 1))
```

$modUtilCode = @'
Option Explicit

' 絵文字はVBAソースコード（cp932）に直接書けないため、設定シートのセル値（S1:S3）を参照する。
Public Function GetTaskStatus(ByVal dueDate As Date, ByVal isDone As Boolean) As String
    Dim wsSet As Worksheet
    Set wsSet = ThisWorkbook.Sheets("設定")
    If isDone Then
        GetTaskStatus = wsSet.Range("S3").Value
    ElseIf dueDate < Date Then
        GetTaskStatus = wsSet.Range("S1").Value
    Else
        GetTaskStatus = wsSet.Range("S2").Value
    End If
End Function
'@

$modFilterCode = @'
Option Explicit

Public Sub RefreshTaskList()
    Dim wsMain As Worksheet, wsSet As Worksheet
    Dim lo As ListObject
    Dim category As String, person As String, keyword As String
    Dim r As Long, outRow As Long
    Dim taskID As Long, cat As String, title As String, per As String
    Dim due As Date, isDone As Boolean, statusText As String

    Set wsMain = ThisWorkbook.Sheets("進捗入力")
    Set wsSet = ThisWorkbook.Sheets("設定")
    Set lo = wsSet.ListObjects("T_タスク")

    category = wsMain.Range("selCategory").Value
    person = wsMain.Range("selPerson").Value
    On Error Resume Next
    keyword = wsMain.OLEObjects("SearchBox").Object.Text
    On Error GoTo 0

    ' 表示域クリア
    wsMain.Range("A6:A75").ClearContents
    wsMain.Range("B6:B75").ClearContents

    outRow = 6
    If lo.ListRows.Count = 0 Then Exit Sub

        taskID = lo.ListRows(r).Range.Cells(1, 1).Value

        per = lo.ListRows(r).Range.Cells(1, 4).Value
        due = lo.ListRows(r).Range.Cells(1, 5).Value

            If person <> "すべて" And per <> person Then GoTo ContinueLoop

        wsMain.Cells(outRow, 1).Value = taskID   ' 列A（非表示）
        wsMain.Cells(outRow, 2).Value = statusText & " " & Format(due, "m/d") & " " & title
        outRow = outRow + 1
        If outRow > 75 Then Exit For

ContinueLoop:
    Next r
End Sub

End Sub

        End If

$modTaskFormCode = @'
Option Explicit

Public Sub PopulateTaskList(ByRef lst As MSForms.ListBox)
    Dim wsSet As Worksheet, lo As ListObject, r As Long
    Set wsSet = ThisWorkbook.Sheets("設定")
    Set lo = wsSet.ListObjects("T_タスク")
    lst.Clear
    For r = 1 To lo.ListRows.Count
        lst.AddItem lo.ListRows(r).Range.Cells(1, 2).Value
        lst.List(lst.ListCount - 1, 1) = lo.ListRows(r).Range.Cells(1, 3).Value
        lst.List(lst.ListCount - 1, 2) = lo.ListRows(r).Range.Cells(1, 1).Value
    Next r
End Sub

Public Function NextTaskID() As Long
    Dim wsSet As Worksheet, lo As ListObject, r As Long, maxID As Long
    Set wsSet = ThisWorkbook.Sheets("設定")
    Set lo = wsSet.ListObjects("T_タスク")
    maxID = 0
    For r = 1 To lo.ListRows.Count
        If lo.ListRows(r).Range.Cells(1, 1).Value > maxID Then maxID = lo.ListRows(r).Range.Cells(1, 1).Value
    Next r
    NextTaskID = maxID + 1
End Function
'@

$frmCode = @'
Option Explicit
Private editingID As Long   ' 0 = 新規追加モード

Private Sub UserForm_Initialize()
    Dim wsSet As Worksheet
    Set wsSet = ThisWorkbook.Sheets("設定")
    Me.cmbCategory.RowSource = "rngCategoryList"
    Me.cmbPerson.RowSource = "rngPersonList"
    modTaskForm.PopulateTaskList Me.lstTasks
    editingID = 0
End Sub

Private Sub btnNew_Click()
    editingID = 0
    Me.cmbCategory.Value = ""
    Me.txtTitle.Value = ""
    Me.cmbPerson.Value = ""
    Me.txtYear.Value = ""
    Me.txtMonth.Value = ""
    Me.txtDay.Value = ""
End Sub

Private Sub btnEditSelected_Click()
    If Me.lstTasks.ListIndex = -1 Then
        MsgBox "一覧からタスクを選んでください。", vbInformation
        Exit Sub
    End If
    Dim wsSet As Worksheet, lo As ListObject, r As Long, targetID As Long
    Set wsSet = ThisWorkbook.Sheets("設定")
    Set lo = wsSet.ListObjects("T_タスク")
    targetID = CLng(Me.lstTasks.List(Me.lstTasks.ListIndex, 2))
    For r = 1 To lo.ListRows.Count
        If lo.ListRows(r).Range.Cells(1, 1).Value = targetID Then
            editingID = targetID
            Me.cmbCategory.Value = lo.ListRows(r).Range.Cells(1, 2).Value
            Me.txtTitle.Value = lo.ListRows(r).Range.Cells(1, 3).Value
            Me.cmbPerson.Value = lo.ListRows(r).Range.Cells(1, 4).Value
            Dim d As Date
            d = lo.ListRows(r).Range.Cells(1, 5).Value
            Me.txtYear.Value = Year(d)
            Me.txtMonth.Value = Month(d)
            Me.txtDay.Value = Day(d)
            Exit For
        End If
    Next r
End Sub

Private Sub btnSaveTask_Click()
    If Len(Trim(Me.txtTitle.Value)) = 0 Then
        MsgBox "タスク名を入力してください。", vbExclamation
        Exit Sub
    End If
    If Len(Trim(Me.cmbCategory.Value)) = 0 Then
        MsgBox "分野を選んでください。", vbExclamation
        Exit Sub
    End If
    If Not IsNumeric(Me.txtYear.Value) Or Not IsNumeric(Me.txtMonth.Value) Or Not IsNumeric(Me.txtDay.Value) Then
        MsgBox "期限を年・月・日とも数字で入力してください。", vbExclamation
        Exit Sub
    End If

    Dim wsSet As Worksheet, lo As ListObject, r As Long
    Dim dueDate As Date
    dueDate = DateSerial(CInt(Me.txtYear.Value), CInt(Me.txtMonth.Value), CInt(Me.txtDay.Value))

    Set wsSet = ThisWorkbook.Sheets("設定")
    Set lo = wsSet.ListObjects("T_タスク")

    If editingID = 0 Then
        Dim newID As Long
        newID = modTaskForm.NextTaskID()
        Dim newRow As ListRow
        Set newRow = lo.ListRows.Add
        newRow.Range.Cells(1, 1).Value = newID
        newRow.Range.Cells(1, 2).Value = Me.cmbCategory.Value
        newRow.Range.Cells(1, 3).Value = Me.txtTitle.Value
        newRow.Range.Cells(1, 4).Value = Me.cmbPerson.Value
        newRow.Range.Cells(1, 5).Value = dueDate
        newRow.Range.Cells(1, 6).Value = False
        newRow.Range.Cells(1, 11).Value = Now
    Else
        For r = 1 To lo.ListRows.Count
            If lo.ListRows(r).Range.Cells(1, 1).Value = editingID Then
                lo.ListRows(r).Range.Cells(1, 2).Value = Me.cmbCategory.Value
                lo.ListRows(r).Range.Cells(1, 3).Value = Me.txtTitle.Value
                lo.ListRows(r).Range.Cells(1, 4).Value = Me.cmbPerson.Value
                lo.ListRows(r).Range.Cells(1, 5).Value = dueDate
                lo.ListRows(r).Range.Cells(1, 11).Value = Now
                Exit For
            End If
        Next r
    End If

    modTaskForm.PopulateTaskList Me.lstTasks
    modFilter.RefreshTaskList
    MsgBox "保存しました。", vbInformation
End Sub

Private Sub btnDeleteTask_Click()
    If Me.lstTasks.ListIndex = -1 Then
        MsgBox "一覧から削除するタスクを選んでください。", vbInformation
        Exit Sub
    End If
    If MsgBox("選択したタスクを削除します。よろしいですか？", vbYesNo + vbQuestion) <> vbYes Then Exit Sub

    Dim wsSet As Worksheet, lo As ListObject, r As Long, targetID As Long
    Set wsSet = ThisWorkbook.Sheets("設定")
    Set lo = wsSet.ListObjects("T_タスク")
    targetID = CLng(Me.lstTasks.List(Me.lstTasks.ListIndex, 2))
    For r = 1 To lo.ListRows.Count
        If lo.ListRows(r).Range.Cells(1, 1).Value = targetID Then
            lo.ListRows(r).Delete
            Exit For
        End If
    Next r
    modTaskForm.PopulateTaskList Me.lstTasks
    modFilter.RefreshTaskList
End Sub

Private Sub btnCancel_Click()
    Unload Me
End Sub
'@

$excel = New-Object -ComObject Excel.Application
$excel.Visible = $false
$excel.DisplayAlerts = $false
$wb = $excel.Workbooks.Open($outPath)
$vbProj = $wb.VBProject

foreach ($comp in $vbProj.VBComponents) {

$mtf.Name = "modTaskForm"
$mtf.CodeModule.AddFromString($modTaskFormCode)

$frmComp = $vbProj.VBComponents.Item("frmTaskEdit")

$wb.Close($false)
$excel.Quit()
[System.Runtime.Interopservices.Marshal]::ReleaseComObject($excel) | Out-Null
Write-Output "frmTaskEdit コード注入完了"

$ErrorActionPreference = "Stop"

## 自己レビュー結果（実施済み）

- **仕様網羅性**：UX設計書の1〜14章すべてに対応するタスクが存在する（3シート構成→Task1、マスタ・移行→Task2、UI→Task3、ステータス判定・絞り込み→Task4、保存・詳細読込→Task5、タスク編集→Task6、使い方・デザイン→Task7、完成基準の動作確認→Task8）。
- **プレースホルダー**：TBD・TODO等は含まれない。全ステップに実行可能なコードを記載済み。
- **型・名称の整合性**：`T_タスク`の列順（ID,分野,タスク名,担当,期限,完了,進捗,現状,課題,今後,更新日時＝1〜11列目）をTask2で定義し、Task4・5・6のコードは全てこの列順を参照している。`selectedTaskID`・`selCategory`・`selPerson`・`chkDoneCell`などの名前付き範囲もTask3で定義したものをTask4以降で一貫して使用している。
- **設計からの逸脱の明記**：検索ボックスのみActiveX TextBoxを採用（Global Constraintsに明記）。理由は「文字入力の都度即時絞り込み」という設計書section 9の要件が、素のセルのWorksheet_Changeイベント（確定時にしか発火しない）では実現できないため。タスク一覧本体は当初の合意通り素のセル＋条件付き書式相当（アイコン文字埋め込み）のまま変更していない。
